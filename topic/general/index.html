On guidance value vs market value in Bengaluru's east, the gap is wide. Knight Frank's H1 2026 flat prices for Whitefield, Marathahalli and KR Puram run about 1.3 to 3.2 times the median apartment guidance value we parsed for the Mahadevapura sub-registrar area.
